✔️How:
Developed an embedded system based on a PIC33 microcontroller, programmed in C with MPLAB. 
Designed electronic boards (power supply and motor control), integrated 5 infrared range sensors, and managed motors using PWM, timers, and ADC
✔️What: 
Designed and built a mobile robot capable of avoiding obstacles using infrared sensors.
✔️Result: 
Autonomous robot able to detect and avoid obstacles in real time, showcasing skills in embedded electronics, low-level programming, and sensor/actuator integration.
